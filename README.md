# Soluções de Pré-Vendas — Estudos de Caso

Exercícios práticos de pré-vendas técnico: a partir de um cenário de cliente, levanto requisitos, desenho a solução e monto o **BOM (Bill of Materials)** com justificativa de cada item.

O objetivo é treinar o raciocínio de quem apoia o time comercial: entender a necessidade, escolher os componentes certos e explicar o porquê.

| 03 | Rede e segurança para filial com 15 usuários | 🔜 |

> Preços são estimativas de referência (out/2026) a partir de catálogos públicos, apenas para dimensionamento.
